# Xの手動返信ガイド（運営が毎日10分、手で行う）

目的: フォロワーが少ないうちは、自分の投稿を置くだけでは誰にも見られない。**同じ読者がいる他のアカウントの投稿に、価値のある返信をして、プロフィールに来てもらう**。
自動返信・自動フォロー・自動いいねはしない（凍結リスク。`docs/X_ACCOUNT_OPERATION.md` の方針）。この文書は「人が手で返す」ためのもの。

> 注意: 具体的なアカウント名は、ここには載せていない。Web検索ではXの中身を確認できず、実在や規模を確かめられない名前を載せると、間違った相手に返す危険があるため。下の「探し方」で、実際のXを見て選ぶ。

## 0. 返信候補の自動調査（運営がやるのは、貼るだけ）
- `x_replies.yml`（1日3回: JST 8:20・12:20・20:20）が、`scripts/x/find-replies.mjs` で、X API の検索（`data/x/reply-targets.json` の queries）から、**いま伸びている恋愛・占い系の投稿**を探し、Claude が**返信案（月・蓮の2案）**まで作って `data/x/reply-candidates.json` に書く
- 候補の条件（`reply-targets.json`）: 投稿から3分〜4時間、いいね20以上、投稿者のフォロワー800〜15万、除外語（Fセク・不倫・勧誘など）を含まない、自分のアカウントでない。勢い（反応÷経過時間）が高い順に最大8件
- 返信案の検査: 宣伝・URL・「フォロー」「プロフ」・体験談風・相手の気持ちの断定・長すぎ、は自動で不合格。Claude が「返信に向かない」（性的・深刻な悩み・勧誘・炎上など）と判断した投稿も除く
- AI社員（毎時の定期実行）が、ホームの `x_replies` に転記し、「X」タブの「返信候補」に出る。運営は、**投稿を開く → 案をコピー → 貼って返信 → 「返信した」を押す**だけ。**自動返信はしない**（案を選び、必要なら言い換えてから、手で送る）
- 特定のアカウントを必ず見たいときは、`reply-targets.json` の `accounts` に、@なしのユーザー名を足す
- 費用: 検索の読み取り量に応じて、X API の料金がかかる（既定は、1回あたり最大60件×1日3回）。**X開発者ポータルの利用状況を、最初の数日は確認する**。Claude APIの費用は、1回あたり数円程度

## 1. 返信する相手の選び方（Xの検索で探す）
条件（すべて満たすものを10〜20アカウント、リストにする）:
- 読者が同じ: 10代後半〜20代の、恋愛・占い・MBTIに関心のある人
- 規模: フォロワー **1,000〜5万** が狙い目。数十万の大手は返信が埋もれる。数十人の相手は、見る人が少ない
- 生きている: 直近1週間で毎日投稿し、返信やいいねが数十〜数百ついている
- 競合ではない: 同じ「占いアプリ」の宣伝アカウントや、広告・勧誘だけのアカウントは避ける

検索ワード（Xの検索で「話題」「最新」を見る）:
- `#恋愛mbti` ／ `恋愛MBTI` ／ `MBTI 恋愛 あるある`
- `片思い 連絡` ／ `脈あり 脈なし` ／ `既読無視` ／ `好きな人 LINE`
- `四柱推命 恋愛` ／ `九星気学 恋愛` ／ `今日の運勢 恋愛`
- `恋愛診断`（診断系のバズ投稿の、返信欄に集まる人を見る）

リストはXの「リスト」機能（非公開）にまとめると、毎日そこだけ見ればよい。

## 2. 返信のやり方（毎日10分・5〜10件）
1. リストの「最新」を開き、**投稿から30分以内**で、すでに反応が伸び始めているものを探す（早い返信ほど見られる）
2. その投稿の内容に、**1つ付け足す**（自分の見方・具体例・小さな問い）。1〜3行
3. 署名は付けなくてよい（返信は短く）。アカウントは「月と蓮 運営」としてプロフィールに明示済み
4. 返信が付いたら、**できる範囲で返す**（会話が続くと、相手のフォロワーにも見られる）
5. やった件数と反応を、末尾の記録表に残す（週1で見直す）

## 3. 返信の型と例文（そのままコピーせず、相手の投稿に合わせて言い換える）
同じ文を複数の相手に送るとスパム扱いされる。**毎回、相手の投稿の中身に触れる**。

| 相手の投稿 | 型 | 例（月＝寄り添う／蓮＝ストレート） |
|---|---|---|
| 「既読無視つらい」など悩みの共感 | 共感＋小さな視点 | 「待ってる時間って、ほんとに長いよね。返信が来ないのは、気持ちが無いからとは限らないから、今日は自分の好きなことで埋めてね」 |
| 「脈ありサイン」リスト | 付け足し | 「③に付け足すなら、『会う予定の話を相手から出す』も大きいと思う。言葉より、時間を使うかが目安」 |
| MBTIの恋愛タイプ紹介 | 自己申告＋問い | 「ISFJの『好きな人ほど、何も言えなくなる』は、わかりやすい特徴だと思う。言えないぶん、小さな気遣いで見せるタイプだよね。同じタイプの人、どんな時にそう感じる？」 |
| 恋愛診断の結果ポスト | 名乗り | 「〇〇タイプ、見た目とのギャップが大きくて面白い診断だね。当てはまった人の反応が気になる」 |
| 「どっち派？」アンケート系 | 答える＋理由 | 「Bの人は、回数より『ちゃんと向き合ってる感』を大事にするタイプが多そう（という見方もできるね）。Aの人は安心感を回数で確かめたい、とか」 |
| 占い・星座の運勢ポスト | 実感の共有 | 「『連絡は夜が吉』、悩んでる人には背中を押してもらえる一言だね。送る前に1回深呼吸、もおすすめ」 |
| 恋愛あるある漫画・イラスト | 共感 | 「スマホを裏返して置くところ、あるあるすぎて笑った。わかる人多そう」 |
| 同規模の運営アカウント | 具体的に褒める | 「この診断の名前の付け方、覚えやすくて好き。〇〇タイプは特に絶妙」 |

### 蓮（ストレートで論理的）の言い方
- 「結論から言うと、〇〇が目安。理由は△△だから」
- 「ここは避けたい。理由は、相手に考える負担を渡すことになるから」

### 月（寄り添う）の言い方
- 「それ、わかるよ。〇〇って不安になるよね」
- 「無理しなくて大丈夫。〇〇してみてね」

## 4. やってはいけないこと
- URL・「無料」・アプリの宣伝・「フォローしてね」を書かない（サイト公開前は「近日」とも言わない。プロフィールで十分）
- 同じ文のコピペ。ひとつの投稿に何度も返信する
- 断定・保証（「必ず両思いになる」）、相手の気持ちの決めつけ
- 悩みの深い投稿（死にたい、DV・ストーカーなど）への占い的な返信。軽い返信はせず、そっとしておく
- 相手を批判する・競合を下げる・炎上中の投稿に乗る
- 1日に10件を超える大量返信（スパム判定のリスク）
- 第三者のふりや、運営が個人として体験したような言い方（「私も悩んでた」「やってみたら当たった」）。運営であることを隠さず、事実でない体験は書かない
