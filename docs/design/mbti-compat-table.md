# 16タイプ（MBTI）相性データベース（16×16・0〜100点）

旧採点（0・10・15・28・34・40点の6段階）では、同点が多すぎるため、心の使い方（認知機能の並び）から、細かい点数を定義した表。`src/data/mbti-compat.json`（生成: `node scripts/build-mbti-compat.mjs`）。

**状態: アプリの採点（ペア鑑定の基本点・16タイプ分、最大40点）に接続済み。** 点数は ×0.4 して四捨五入（0〜100点→0〜40点）。エンジンは import を持てないため、表は `src/utils/fortuneEngine.ts` の `MBTI_COMPAT_100` に同じ値を置き、`npm run test:engine` で JSON との一致を確認する。

## 定義（点数への換算の重みは、アプリが決めた値＝オリジナル）
- 同じ心の使い方を、同じように重んじる度合い（機能と向きの一致）
- 文字（N/S/T/F）の一致度
- 補い合い（自分の苦手を、相手の得意が補う）
- E/I・S/N・T/F・J/P の組み合わせ
- 従来の「理想の組」（アプリの旧表 idealPairs）は、上位の帯（70〜100点）に入れる。旧表が一方向にしか書かれていなかった3組（ENFP×INFJ、ENFP×INTJ、ESFP×ISTJ）も、両方向に揃えた
- 性別で重みは変えない。表は、男性・女性を入れ替えても同じ（対称）

## 限界（確認した事実）
- 異なる点数は19段階（256組中、同点の最大は32組）。16タイプの構造が対称なため、認知機能から定義する限り、これ以上は、細かくできない（2通りの方式を試した結果）
- 256組をすべて区別するには、男性側・女性側で重みを変えるなど、根拠のない調整が必要になる
